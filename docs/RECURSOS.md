## Recursos de código

- Placeholders SVG, favicon, iconos y composiciones sociales: dibujos propios deterministas del proyecto. Regenerador: `scripts/create-demo-assets.mjs`.
- Tarjetas sociales PNG: una composición específica para Bruma y otra para Olivo, generadas con Sharp.
- Fuentes autohospedadas mediante Fontsource: DM Sans y Cormorant Garamond, licencias SIL OFL incluidas en los paquetes.

Sustituir las marcas y datos ficticios antes de una entrega real. La imagen social de cada cliente debe reflejar su identidad final.
